`CormorantGaramond.ttf` is the unmodified regular variable TrueType font from
[Google Fonts](https://github.com/google/fonts/tree/main/ofl/cormorantgaramond).
Copyright 2015 the Cormorant Project Authors. Its SIL Open Font License 1.1 is
included in `OFL.txt`. Paint reads the font's default instance; it does not
interpret variation axes or execute hinting instructions.
